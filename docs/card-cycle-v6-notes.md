# Card Cycle V6

Animation uniquement : aucune modification des règles.

- Pas d'animation pendant le tour IA / adverse.
- 5 cartes de pioche plus grandes, étalées et centrées au-dessus de Déplacer / Pousser / Magie.
- Compteurs de pioche regroupés par type à l'arrivée (+N).
- Une action qui consomme plusieurs cartes (ex. déplacement x3) produit une seule animation avec badge ×3.
- Les événements main + réserve d'une même action sont regroupés pendant une courte fenêtre afin d'éviter deux animations.
- Fin de tour : les cartes inutilisées sont regroupées par type vers la réserve ; éventuel surplus vers la défausse.
- Cache frontend passé en V6.
