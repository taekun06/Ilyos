# Assets du nouveau menu

Le module attend exactement ces trois fichiers :

- `home-bg.svg` : fond du Menu 1, sans HUD ni logo intégré.
- `duel-bg.svg` : illustration Chevalier vs Mage utilisée aussi par la transition en deux moitiés.
- `ilyos-logo.svg` : logo ILYOS transparent.

Vous pouvez remplacer plus tard une image sans modifier le code : conservez simplement le même nom de fichier.
