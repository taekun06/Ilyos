# Nouveau menu ILYOS

Ce dossier est volontairement autonome.

- `menu.css` : apparence, dimensions, HUD et animations.
- `menu.js` : affichage, parallaxe, particules et transition Menu → Duel.
- `menu-config.js` : textes des modes et correspondances avec le jeu.
- `menu-bridge.js` : seul point de contact avec l’ancien écran de configuration et `game.js`.
- `assets/` : images du menu. Vous pouvez remplacer une image en conservant le même nom.

Le cœur du jeu ne doit pas être modifié pour changer l’apparence du menu.
